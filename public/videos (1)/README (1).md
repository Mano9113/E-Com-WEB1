# Add Your Videos Here

## Optional Videos:
- hero-bg.mp4 - Background video for hero section (loops, no sound needed)
- wedding.mp4 - Portfolio video
- bts.mp4 - Behind the scenes

## Recommended Settings:
- Format: MP4 (H.264)
- Hero video: 1920x1080, 10-30 seconds, looping
- Portfolio videos: 1280x720 or higher
- Keep file sizes small (compress for web)

## Tips:
- Hero background video should be subtle (slow motion works well)
- Portfolio videos can be event highlights, reels, etc.
